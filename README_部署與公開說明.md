# 評量偵探室 v4｜全班匿名觀點牆

這個版本延續語音輸入 v3、投影片同步五關與 Google Sheet 儲存，只解決「教師無法讓學員看到彼此文字回答」的問題。

## v4 的上課流程

1. 學員輸入姓名，進入五關，選擇答案並說明理由（可使用語音輸入轉文字）。
2. 每關的「同意匿名分享」預設勾選，但學員可以自行取消；未同意時仍可完成作答與納入選項統計。
3. 教師使用 `你的GitHub頁面網址?mode=host` 登入主持教師看板。
4. 教師可先把「預計參與人數」設成 0，讓各關只由手動公布。
5. 當大家提交後，按該關「公布觀點牆」。這 **一個按鈕** 同時開放統計與已同意分享的匿名文字。
6. 學員在已完成該關時，按「↻ 更新」，再按「▦ 開啟全螢幕觀點牆」看所有已同意分享的文字（依選項 A／B／C／D 篩選）。
7. 教師端可按「▦ 投影觀點牆」，投影匿名回答，避免在公開投影畫面洩漏姓名。

## 部署順序（前端與後端必須同時更新）

### A. 先更新 Google Apps Script

1. 用原本的 Google Sheet > 擴充功能 > Apps Script 進入 **原專案**。
2. 先安全抄下舊 `Code.gs` 的 `SPREADSHEET_ID` 與 `HOST_PIN`，不要把 PIN 放在 GitHub 或傳給他人。
3. 將本包 `backend/Code.gs` 整份複製進原專案，填回自己的 ID 與 PIN。`ROOM_CODE` 保持 `assessment-lab-2026`。
4. 儲存後執行一次 `setup()`（若工作表已存在且欄名相同，程式只會檢查設定，不清除作答）。
5. 點「部署 > 管理部署作業」，選擇 **現在使用的那個部署**，按「編輯」，將「版本」選「新增版本」，再按「部署」。**不要新增一個不同的 Web App 部署**。
6. 用瀏覽器打開：
   https://script.google.com/macros/s/AKfycbySeOSaKYMSDem6ItsI4ErfK7qIxgpIzMFNUu53xg7td7kZVzmvQM28w-RysXXml-zvHQ/exec?action=health&room=assessment-lab-2026
   確認回傳包含 `"version":"slidesync-2026-11-v4-wall"`。

### B. 再更新 GitHub Pages

1. 將 `site/` 的 `index.html`、`app.js`、`style.css`、`config.js` 放入原本 GitHub Pages 儲存庫 **根目錄**（或原本 Pages 發布的位置），覆蓋舊檔。
2. `config.js` 已填入你提供的 Apps Script `/exec` 網址；不需要改除非你後來換了部署。
3. GitHub Pages 更新完成後，重新整理網頁（必要時強制重新整理以清除快取）。
4. 網頁版本與後端必須相同；若出現後端仍是舊版的提示，請檢查 A5 是否選了「新增版本」。

## 隱私與舊答案

- Google Sheet 保留學員真實填答姓名，供 **主持教師** 匯出、核對；觀點牆不顯示姓名。
- 從 v4 開始，學員新作答時「同意匿名分享」預設勾選，並可取消。請在課堂口頭提醒大家：文字將展示給能使用課堂連結的人，不代表只有班級成員能看。
- **舊版已作答但未勾選公開同意的文字不會自動出現在觀點牆。** 舊學員須重新登入，以原來的姓名進入該關，勾選「同意匿名分享」，再按「更新我的回答」。
- 不要輸入可識別的幼兒姓名、學校或個案細節，也不要將觀點牆截圖轉傳到班級以外。
- 姓名登入只是方便讀取進度，不是安全的驗證；若需要限制班級以外的人觀看，必須額外建立真正的身分驗證機制。

## 本機試玩

可開啟同包 `demo.html`，不會連到 Google Sheet。單一瀏覽器可換不同姓名模擬作答，並用 `?mode=host` 嘗試教師看板；試玩資料只在該瀏覽器，與正式雲端無關。正式使用時不要加 `?demo=1`。
